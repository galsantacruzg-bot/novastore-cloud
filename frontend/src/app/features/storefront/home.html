EL FUTURO DE NOVASTORE

Una tienda que crece contigo.

NovaStore es una plataforma de comercio electrónico construida para evolucionar: catálogo dinámico, inventario, carrito y pedidos registrados mediante una API REST y una base de datos relacional.

Versión académica demostrativa: todavía no procesa pagos reales ni garantiza entregas comerciales.
